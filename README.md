# HeatShield Mumbai

Ward-level heat vulnerability for Mumbai, built on a knowledge graph you can question in plain English (GraphRAG).

- **Real data:** BMC ward boundaries (DataMeet), Census 2011 ward tables (MCGM), and 1,554 hospitals, parks and drinking-water points from OpenStreetMap. Estimated or illustrative inputs are labelled as such everywhere.
- **Knowledge graph:** 1,697 nodes and 1,792 relationships linking wards, neighbours, facilities, population groups, policy sections and heat alerts. It runs on Neo4j when available, otherwise on an in-memory graph queried with a real Cypher interpreter (GrandCypher).
- **GraphRAG:** entity linking → hybrid document search (BM25 + embeddings or LSA, fused with RRF) → text-to-Cypher → execution with one self-repair → a grounded answer citing graph rows and passages. It works with a Gemini key, any OpenAI-compatible model, or no key at all (rule-based).
- **Heat Vulnerability Index:** exposure, sensitivity and adaptive capacity, with live re-weighting.

**New to the project? Read [LEARN.md](LEARN.md)**: every part explained in plain words, plus viva practice questions.

## Run it

Requirements: Python 3.11+, Node 18+.

```bash
# 1. Backend
python -m venv .venv
.venv\Scripts\Activate.ps1            # Windows   |  source .venv/bin/activate  (macOS/Linux)
pip install -r requirements.txt
cp .env.example .env                  # optional: add GEMINI_API_KEY for AI-written answers
uvicorn backend.main:app --reload --port 8000

# 2. Frontend (new terminal)
cd frontend
npm install
npm run dev                           # → http://localhost:5173
```

API docs: http://localhost:8000/docs · Tests: `pytest backend/tests -q` (30 tests)

### Optional extras

| Want | Do |
| --- | --- |
| AI-written Cypher and answers | Set `GEMINI_API_KEY` in `.env` (free key at aistudio.google.com/apikey) |
| Neo4j instead of the in-memory graph | `docker run -d -p 7474:7474 -p 7687:7687 -e NEO4J_AUTH=neo4j/heatshield123 neo4j:5`, then restart the backend |
| Fresh OpenStreetMap data | `python -m scripts.fetch_osm && python -m scripts.build_datasets` |
| Index the full official plans | Put the PDFs in `data/documents/` and list them in `manifest.json` |

## Project layout

```
backend/
  api/routes.py               REST endpoints
  core/vulnerability_model.py HVI scoring
  core/imd_criteria.py        IMD coastal heatwave rules
  graph/connection.py         Neo4j / GrandCypher engine + read-only guard
  graph/ontology.py           node and relationship schema (also given to the LLM)
  graph/documents.py          document chunking, ward-mention linking, alert extraction
  graph/vector_store.py       hybrid search (BM25 + embeddings/LSA, RRF)
  graph/graphrag_engine.py    the GraphRAG pipeline
  graph/llm.py                Gemini / OpenAI-compatible client
  ingestion/ingest_all.py     builds the graph at start-up
data/
  sources/                    raw inputs (real + labelled estimates)
  processed/                  generated by scripts/build_datasets.py
  documents/                  policy documents + manifest
frontend/src/
  pages/                      Overview, Map, Ward rankings, Ask, Knowledge graph, Query lab, Documents, Data & method
  components/                 Shell, WardMap (Leaflet), GraphView (vis-network), UI parts
docs/UI_REVIEW.md             design and accessibility review of the dashboard
```

## Data sources

| Data | Source | Status |
| --- | --- | --- |
| Ward boundaries | [DataMeet Municipal_Spatial_Data](https://github.com/datameet/Municipal_Spatial_Data) | Real |
| Population, slums, children 0–6, literacy | Census of India 2011, ward table published by MCGM Public Health Dept. | Real |
| Hospitals, parks, drinking water | OpenStreetMap contributors (ODbL), via Overpass API | Real |
| Surface temperature, NDVI, hotspots | Hand-entered representative values | Estimate |
| Cooling shelters | Examples | Illustrative |
| Heat Action Plan, MCAP 2022, IMD criteria | Team summaries of the official documents | Summary |

The index ranks wards relative to each other for planning. It does not predict individual health risk.
